# v1.3.0 — 修复初始化链路（桌面图标 / 手机 IP 读取）

> 这版没有新功能。修的是几个**静默失败** —— 不报错、不崩溃，只是没生效。

## 一句话

以前 `setup.bat` 会显示 `[OK] 初始化完成！`，但桌面**不会**出现图标；
手机换了网络后还可能卡在「读取不到 WiFi IP」。现在都好了。

## 修了什么

| 问题 | 现象 | 根因 |
|---|---|---|
| 桌面图标不生成 | 初始化显示成功，桌面没图标 | `setup.bat` 判断的是 `create-shortcut.vbs`，仓库里根本没这个文件 → `if exist` 恒假，整块静默跳过 |
| 读不到手机 IP | 手机连着 WiFi 却报「文件名、目录名或卷标语法不正确」 | `for /f` 里给 `!ADB!` 加了引号（破坏解析）+ `tokens=2 delims=/` 取错字段 |
| 快捷方式脚本崩溃 | `catch : 无法将"catch"项识别为 cmdlet` | `.ps1` 是 UTF-8 无 BOM，中文 Windows 的 PowerShell 5.1 按 GBK 误读，把引号吞掉 |
| 设备名带引号 | `"192.168.101.48:5555"` | `call :accept_if_android "%%a"` 的引号被带进了变量 |
| 「已连接」打印两次 | 输出重复 | 第 1 步与 `:launch` 各打一次 |

## 为什么以前没发现

这些都是**静默失败**：脚本不报错、退出码是 0，只是功能没生效。
`setup.bat` 甚至会在没创建图标的情况下打印「桌面上已生成…快捷方式」。

## 验证

Windows 11 + realme RMX5010 (Android 16 / SDK 36)

- scrcpy **3.3.3** 与 **4.1** 均实测通过
- 删掉图标 → 跑 `setup.bat` → 图标自动生成 ✅
- 双击图标 → 投屏正常启动 ✅
- 手机 IP 读取：修复前返回空，修复后返回 `192.168.101.48` ✅

## 变更清单

- **修复** `setup.bat` 读取手机 WiFi IP 失败（两个错误叠加）
- **修复** `setup.bat` 创建桌面快捷方式从未生效（引用了不存在的文件）
- **修复** `scripts/create-shortcut.ps1` 中文 Windows 下语法崩溃（补 UTF-8 BOM）
- **修复** `launch.bat` 设备名带引号、重复打印
- **更新** README 实测环境补充 scrcpy 4.1
- 版本不删除：v1.0.0 / v1.1.0 / v1.2.0 的标签与代码均完整保留
