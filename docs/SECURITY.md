# 安全说明 / Security Policy

## 关于 adb tcpip 的安全提醒

本项目使用 `adb tcpip 5555` 将手机的 adb 调试接口开放到局域网。这是一个
**官方支持但需要谨慎使用**的功能，请注意以下几点。

### 风险是什么

启用后，同一局域网内**任何设备**只要知道手机 IP，都可以通过 adb 连接手机，
并拥有与 adb 调试同等的权限（读写文件、安装应用、模拟输入、截屏等）。

### 使用建议

| 场景 | 建议 |
|---|---|
| 家庭 / 个人办公网络 | 可以正常使用 |
| 公司网络 | 确认 IT 政策允许，或仅在需要时开启 |
| 公共 WiFi（咖啡厅、机场、酒店） | **不要使用** |
| 使用完毕后 | 可执行 `adb usb` 关闭 TCP 模式 |

### 降低暴露面的做法

1. **用完即关**
   ```bash
   adb usb          # 切回 USB 模式，关闭 TCP 监听
   ```
   注意：本项目的 `setup` 会重新开启它，所以关闭后需重跑 setup 才能无线投屏。

2. **改一个非默认端口**
   ```bash
   adb tcpip 47000
   ```
   然后修改 `config.ini` 里的 `PORT=47000`。默认端口 5555 最容易被扫描到。

3. **限制网络访问**
   在路由器上隔离 IoT 设备，或使用访客网络，避免同网段存在不受信任的设备。

4. **Android 11+ 的「无线调试」配对机制**
   如果你在意安全性，可以考虑使用 Android 11 引入的官方无线调试
   （`adb pair`），它带有配对码校验。本项目当前基于 `tcpip` 方案，
   原因是它在旧版本 Android 和各类厂商 ROM 上兼容性更好。

## 关于本项目代码

- 本项目**只调用 scrcpy 官方发行包自带的 `adb` 与 `scrcpy`**，
  不附带、不修改任何二进制文件
- 所有脚本均为纯文本，可自行审阅
- 项目不会向任何服务器发送数据

### 脚本会做什么

| 操作 | 说明 |
|---|---|
| `adb start-server` | 启动本地 adb 服务 |
| `ping <PHONE_IP>` | 探活，判断手机是否在线 |
| `adb connect <IP>:<PORT>` | 建立无线连接 |
| `adb devices` | 列出设备 |
| 读写 `config.ini` | 保存你的配置 |
| 创建桌面快捷方式 | 仅在显式运行时（需 pywin32 或 PowerShell） |

不会做：上传数据、修改系统设置、静默安装任何东西。
