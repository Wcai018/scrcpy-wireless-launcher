# v1.3.1 — setup.bat 自动搜索 scrcpy

> 小更新：以前 scrcpy 装在非标准位置就找不到、要手动输路径；现在会自己去电脑里搜。

## 一句话

新下载的副本没有 `config.ini`（它含个人 IP，被 `.gitignore` 忽略），
所以以前每个人第一次跑 `setup.bat` 都得手动填 scrcpy 路径。现在不用了。

## 修了什么

| 问题 | 现象 | 根因 |
|---|---|---|
| 找不到 scrcpy | `[X] 没有找到 scrcpy.exe`，要求手输路径 | 原定位只查项目根目录、`config.ini`、`PATH`、5 个写死位置；新副本没有 `config.ini`，其余全不命中 |

## 现在怎么找

按顺序命中即停：

1. 项目根目录的 `scrcpy.exe`
2. 项目根目录下的 `scrcpy*` 子目录
3. `config.ini` 里的 `SCRCPY_DIR`
4. **与启动器同一层 / 上一层的 `scrcpy*` 目录** ← 覆盖「解压在一起」的情况
5. `PATH`
6. 常见位置（含 `Downloads\scrcpy*`、`Desktop\scrcpy*`）
7. **全盘两层扫描 `<盘>:\*\scrcpy*`** ← 最后手段
8. 都没有 → 手动输入

## 两个设计取舍

**扫描很快**：只枚举目录名、不递归扫文件，实测 C/D 两盘 0.2 秒。

**找到多个副本时不猜**：实测会同时扫到新旧版本。静默取第一个可能取到旧的，
所以 1 个候选才自动采用；多个则编号列出让你选。

## 实测

- 删掉 `config.ini` → 运行 `setup.bat` → 第 1 步自动定位到
  `D:\Wcai\scrcpy-win64-v4.1`，全程无手动输入 ✅
- 全盘扫描 0.2 秒完成 ✅
